# Diagrams

Drawn with [Excalidraw](https://excalidraw.com). Each diagram exists once per language (`en`, `pt-BR`) in three files:

| File | Use |
|---|---|
| `<name>.<lang>.excalidraw` | the source; open it on excalidraw.com (Ctrl+O) to edit by hand |
| `<name>.<lang>.svg` | light theme, used by the docs |
| `<name>.<lang>.dark.svg` | dark theme, picked by GitHub through `<picture>` when the reader uses dark mode |

The `.excalidraw` files are generated by `src/gen.py` and exported by `src/export.mjs`, which runs Excalidraw's own `exportToSvg` in Playwright's Chromium, so the hand-drawn font is inlined in each SVG:

```bash
python3 docs/diagrams/src/gen.py
node docs/diagrams/src/export.mjs        # --png also writes previews
```

Edited a diagram by hand on excalidraw.com? Save it over its `.excalidraw` file and run only `export.mjs`; running `gen.py` again would overwrite the hand edits.

Drawing conventions the generator follows: short names inside boxes, explanations in dashed notes outside them, unlabelled arrows that only curve where they bend, a stick figure for people, a coloured dashed zone per area, hachure fill (green for an end state, red for a bug), a legend when solid and dashed arrows mean different things, and text in `#1e1e1e` so Excalidraw shows it white in dark mode.
